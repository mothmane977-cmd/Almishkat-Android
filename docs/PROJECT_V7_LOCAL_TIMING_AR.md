# ALMISHKAT V7 — حفظ التوقيتات محلياً

## ما أضيف
- جدول SQLite جديد لتوقيتات الآيات.
- مفاتيح التوقيتات تتضمن الرواية والسورة ورقم الآية.
- حفظ بداية ونهاية كل آية ومرجع ملف الصوت URI وتاريخ آخر تعديل.
- تحميل التوقيتات عند فتح شاشة المزامنة.
- حفظ التعديلات تلقائياً بعد تغيير التوقيت.
- ترقية قاعدة البيانات من الإصدار 1 إلى 2 دون حذف جداول القرآن أو بياناتها.

## حدود التنفيذ
- ربط التوقيتات في شاشة V7 مضبوط حالياً على سورة الفاتحة (السورة 1) لأن نموذج الشاشة الحالي يحتوي سبع خانات فقط.
- مرجع URI يحفظ كسلسلة؛ يلزم إضافة إدارة صلاحيات URI الدائمة والتحقق من بقاء الملف متاحاً عند استعادة المشروع.
- لا توجد بعد إدارة مشاريع متعددة أو حفظ ملفات الصوت داخل مساحة التطبيق.
- لا توجد محاذاة تلقائية ولا موجة صوت مرئية.
- يجب بناء المشروع واختباره على جهاز Android قبل اعتبار الوظيفة معتمدة.
