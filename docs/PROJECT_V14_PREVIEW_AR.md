# ALMISHKAT V14 — معاينة المشهد وتشغيل نطاق التلاوة

## ما أضيف
- تبويب مستقل لمعاينة الفيديو داخل الاستوديو.
- لوحة تصميم عمودية بنسبة 9:16 بخلفية مرسومة محلياً.
- تحميل أحدث نطاق صوتي محفوظ من SQLite.
- قراءة الرواية والسورة والآية المرتبطة بالنطاق.
- عرض نص الآية فقط إذا كان موجوداً في قاعدة البيانات المحلية؛ وإظهار حالة واضحة إذا لم تتوفر بيانات موثقة.
- تشغيل مصدر الصوت من URI مع بدء التشغيل عند بداية النطاق وإيقافه عند نهاية النطاق.
- عرض موضع التشغيل وحالة أخطاء الوصول إلى الصوت.

## حدود النسخة
- لا يوجد إخراج MP4 أو دمج فيديو فعلي.
- الخلفية مرسومة داخل Compose وليست ملف فيديو/صورة مستورداً.
- لا يوجد تحريك تلقائي للآيات على خط زمني متعدد الآيات؛ المعاينة تعرض آية واحدة مرتبطة بآخر نطاق محفوظ.
- لا يوجد تحكم متقدم في الخطوط أو الحركات أو انتقالات المشاهد.
- تشغيل URI يعتمد على بقاء صلاحية الوصول إلى الملف؛ ينبغي تثبيت صلاحية URI الدائمة عند اختيار الملف في تحسين لاحق.
- لم يُبنَ APK أو يُختبر على جهاز Android فعلي.
