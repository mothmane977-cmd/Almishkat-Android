# ALMISHKAT V8 — إدارة المشاريع المحلية

## ما أضيف
- جدول SQLite لإدارة مشاريع الاستوديو.
- إنشاء مشروع باسم يحدده المستخدم.
- تخزين الرواية والسورة والقالب ونسبة أبعاد الفيديو ومرجع الصوت وتواريخ الإنشاء والتحديث.
- عرض المشاريع مرتبة حسب آخر تحديث.
- حذف مشروع.
- ترقية قاعدة البيانات من الإصدار 2 إلى 3 مع الحفاظ على الجداول السابقة.

## حدود هذه النسخة
- المشروع يحفظ بياناته الوصفية فقط؛ لا يحفظ بعد ملف فيديو أو نسخة من الصوت أو إعدادات جميع عناصر التصميم.
- لا توجد شاشة فتح/استعادة كاملة للمشروع داخل المحرر بعد.
- التوقيتات تحفظ في جدول مستقل لكن لا ترتبط بعد بمعرف المشروع؛ هذه نقطة لازمة قبل دعم مشاريع متعددة بالكامل.
- لا يوجد تصدير أو نسخ احتياطي سحابي.
- يلزم بناء المشروع واختباره على Android.
