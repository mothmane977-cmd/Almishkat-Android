# إصلاح V25 — انهيار شاشة المصحف

## سبب المشكلة
شاشة الاستوديو الرئيسية في `MainActivity.kt` تستخدم `verticalScroll` للحاوية التي تعرض محتوى التبويبات. وكانت `QuranReaderScreen.kt` تضيف `verticalScroll` ثانية داخلها، ما يسبب قيود قياس غير محدودة لمكونات التمرير العمودي في Compose وقد يؤدي إلى انهيار التطبيق عند فتح تبويب المصحف.

## التعديل
أزيل `verticalScroll(rememberScrollState())` من حاوية `QuranReaderScreen` وأزيل الاستيرادان المرتبطان بها. أصبحت الشاشة تعتمد على حاوية التمرير الموجودة في `MainActivity.kt`.

## ما لم يتغير
- قاعدة بيانات المصحف واستعلاماتها.
- الروايات واختيار السورة والآية.
- شاشة المزامنة.
- الاستوديو والصوت والمشاهد والتصدير.
- بنية المشروع وبقية الملفات.

## الاختبار
يجب بناء التطبيق عبر GitHub Actions ثم تثبيت APK وتجربة فتح تبويب «المصحف»، تغيير السورة، وتغيير رقم الآية. لم يتم تنفيذ بناء Android فعلي في هذه البيئة.
