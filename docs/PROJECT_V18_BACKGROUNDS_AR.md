# ALMISHKAT V18 — مكتبة الخلفيات والصور

## ما أضيف
- شاشة خلفيات مرتبطة بالمشروع.
- أربعة قوالب لونية محلية: زمردي، ليلي، ذهبي هادئ، وساج.
- استيراد صورة من الهاتف عبر Android OpenDocument مع محاولة حفظ صلاحية القراءة الدائمة.
- حفظ URI الصورة والقالب وخيار الحركة في SQLite.
- ترقية قاعدة البيانات إلى الإصدار 7.
- تمرير الخلفية للمحرك ورسم الصورة بتعبئة قصّية تحافظ على نسبة المشهد 9:16.
- حركة تكبير تدريجية خفيفة اختيارية أثناء التصدير (Ken Burns).
- تعتيم بسيط فوق الصورة لتحسين تباين النص.

## حدود النسخة
- استيراد الصور الثابتة فقط؛ ملفات الفيديو كخلفية لم تُنفذ بعد.
- لا توجد انتقالات بين المشاهد أو مكتبة أصول مرفقة جاهزة؛ القوالب الحالية تدرجات لونية.
- معاينة شاشة الخلفية تعرض الطابع اللوني ومعلومات الصورة، وليست عرضاً مباشراً للصورة المستوردة.
- إذا فشل فك الصورة أو انتهت صلاحية URI، يعود المحرك إلى الخلفية اللونية.
- لم يتم تشغيل Gradle أو بناء APK أو اختبار التصدير على هاتف فعلي.
- يلزم لاحقاً تقليل ضغط الذاكرة وفحص صور ضخمة جداً وإدارة أخطاء الصور التالفة.
