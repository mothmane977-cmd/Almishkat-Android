# ALMISHKAT V17 — التحرير البصري وربط الطبقات بالتصدير

## ما أضيف
- معاينة مشهد 9:16 تفاعلية في تبويب طبقات المشهد.
- تحريك الطبقات النصية بالسحب مع حفظ الإحداثيات النسبية.
- اختيار طبقة وتعديل حجم الخط.
- تعديل زمن بداية ونهاية ظهور الطبقة بالمللي ثانية.
- اختيار طبقات المشروع من قاعدة SQLite وتمرير المرئية منها إلى محرك التصدير.
- رسم الطبقات في إطارات MP4 بحسب نطاق ظهورها وترتيب z-order وموقعها وحجمها.
- طبقات النص القرآني والعناوين والتعليقات والزخارف تستخدم لوناً افتراضياً حسب النوع.

## حدود النسخة
- محرر السحب يحرر النصوص، ولا يدعم بعد الصور أو الفيديو كطبقات مرئية.
- التصدير يرسم نص كل طبقة كسطر واحد مع حد 180 محرفاً؛ التفاف العربية الطويلة وتشكيلها يحتاج تحسيناً وتدقيقاً.
- عند وجود طبقات محفوظة، تُستخدم الطبقات بدلاً من نص الآية الافتراضي في مسار التصدير؛ ينبغي إضافة طبقة الآية من قاعدة المصحف ضمن المشروع.
- لا توجد خلفيات فيديو متحركة أو انتقالات أو keyframes أو تحريك تدريجي.
- لا يوجد اختبار Gradle أو بناء APK أو اختبار جهاز فعلي في هذه الجلسة.
