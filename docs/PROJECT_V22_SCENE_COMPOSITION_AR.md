# ALMISHKAT V22 — تركيب مستقل لكل مشهد

## ما أضيف
- ترقية SQLite إلى الإصدار 10 مع scene_id لطبقات النص والخلفيات.
- الإبقاء على السجلات القديمة المرتبطة بالمشروع دون حذف.
- مفتاح مركب (project_id, scene_id) لجدول الخلفيات حتى يملك كل مشهد خلفيته، مع ترحيل السجلات القديمة.
- ربط صورة أو فيديو بخلفية مشهد محدد.
- إضافة طبقات نصية خاصة بكل مشهد.
- شاشة «تركيب المشاهد» لاختيار المشروع والمشهد وإدارة موارده.
- حفظ صلاحيات قراءة ملفات الهاتف المختارة.

## الحدود
- محرك MP4 لم يقرأ بعد قائمة المشاهد وخلفياتها وطبقاتها بالتتابع.
- الشاشة الحالية تضيف طبقة عنوان؛ المحرر المتقدم للطبقات ما زال منفصلاً.
- لا يوجد بناء APK أو اختبار جهاز فعلي.
