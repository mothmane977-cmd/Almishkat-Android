# ALMISHKAT V6 — قارئ المصحف

## المنفذ
- تبويب قارئ مستقل داخل محرر الاستوديو.
- اختيار رواية حفص أو ورش.
- قائمة بأسماء السور الـ114.
- تنقل بين أرقام الآيات.
- استعلام مباشر من قاعدة SQLite المحلية بحسب الرواية.
- حالة فارغة آمنة لا تعرض نصاً غير موثّق.

## غير المنفذ بعد
- لم تدمج النصوص الرسمية أو الخطوط القرآنية.
- لا يوجد عرض صفحات مصحف مطابق لطبعة محددة.
- لا يوجد بحث نصي أو علامات وقف/أجزاء/أحزاب أو حفظ موضع القراءة.
- لا يوجد ربط تفاعلي مباشر لإرسال الآية إلى محرر الفيديو.
- يجب اختبار البناء على Android قبل اعتماد APK.
