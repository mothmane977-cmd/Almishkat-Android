# ALMISHKAT STUDIO — حزمة تأسيسية للبناء عبر الهاتف

## ما الذي تحتويه؟
- مشروع Android أصلي بـ Kotlin وJetpack Compose.
- واجهة تأسيسية عربية وهوية ليلية/ذهبية.
- GitHub Actions لبناء APK تجريبي في السحابة دون الحاجة إلى حاسوب.

## بناء APK من الهاتف
1. أنشئ حساباً في GitHub إن لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً باسم `almishkat-studio`.
3. ارفع محتويات هذا المجلد إلى المستودع (يمكن رفع ZIP ثم فك الملفات محلياً، أو استخدام واجهة GitHub لإضافة الملفات).
4. افتح تبويب Actions في المستودع.
5. اختر `Build Android APK` ثم `Run workflow`.
6. بعد نجاح المهمة، افتح نتيجة التشغيل ونزّل Artifact باسم `almishkat-debug-apk`.
7. فك ضغط Artifact وثبّت `app-debug.apk` على هاتفك. قد يطلب Android السماح بالتثبيت من هذا المصدر.

## ملاحظات مهمة
- هذا APK تجريبي للواجهة فقط، وليس المنتج الكامل.
- لا توجد بعد قاعدة بيانات مشاريع أو نص قرآني متصل بمصدر معتمد أو تشغيل صوت أو مزامنة أو تصدير فيديو.
- لا تستخدمه للنشر أو للاعتماد عليه في عرض نصوص قرآنية قبل تنفيذ مصدر النص والتحقق منه.
- ملف Gradle Wrapper غير مضمن؛ يستخدم GitHub runner نسخة Gradle المثبتة. يمكن إضافة Wrapper لاحقاً لتثبيت بيئة البناء.

## تحديث V3 — محرك التلاوة والتزامن الأولي
- اختيار ملف صوت من الهاتف عبر منتقي ملفات Android (audio/*).
- تشغيل/إيقاف الصوت، شريط تقدم، وعرض المدة والموضع الحالي.
- خط زمني من سبع خانات للفاتحة مع ضبط بداية ونهاية كل آية يدوياً.
- اكتشاف الآية النشطة وفق موضع التشغيل.

- دمج شاشة التزامن داخل تبويب «التزامن» في الاستوديو.

### حدود هذه النسخة
- بيانات السورة الحالية نموذج أولي للفهرسة الزمنية فقط؛ لا تتضمن نص الآيات.
- لم يُضف بعد مصدر مصحف موثّق أو بيانات علامات الوقف أو الروايات.
- لم يُنفّذ بعد الحفظ الدائم لمشاريع التوقيت، أو المحاذاة التلقائية للكلمات، أو تصدير الفيديو.
- يجب اختبار البناء والتشغيل على جهاز Android فعلي قبل اعتماد APK.
