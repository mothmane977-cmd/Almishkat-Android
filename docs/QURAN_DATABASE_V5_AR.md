# ALMISHKAT V5 — قاعدة البيانات القرآنية المحلية

## ما أضيف في الكود
- SQLite محلية تعمل دون اتصال.
- جدول مستقل لآيات حفص وجدول مستقل لآيات ورش.
- سجل مصدر يتضمن الاسم والإصدار والرابط وبصمة SHA-256 وعدد الآيات وتاريخ الاستيراد.
- استيراد ذري؛ إما اعتماد مجموعة البيانات كاملة أو التراجع عنها.
- رفض الملف عند اختلاف البصمة أو الرواية أو نقص السور أو خلل تسلسل الآيات.
- استرجاع آية حسب الرواية والسورة والآية.

## عقد الاستيراد الداخلي
{
  "riwayah": "HAFS",
  "ayahs": [
    {"surah": 1, "ayah": 1, "text": "...", "juz": 1, "page": 1}
  ]
}
هذا مثال بنيوي فقط، وليس نصاً قرآنياً أو ملف بيانات جاهزاً.

## المرجع الرسمي
منصة مطوري مجمع الملك فهد تتيح صيغاً مثل SQL وJSON وXML وCSV، وتعرض موارد منفصلة لحفص وورش. يجب تنزيل ملف كل رواية من المصدر الرسمي وفحص شروط الاستخدام والبصمة قبل إدراجه:
https://qurancomplex.gov.sa/quran-dev/

## ما لم يكتمل بعد
- لم تُنزّل أو تُضمّن النصوص الرسمية داخل المشروع.
- لا توجد بيانات قرآنية فعلية مثبتة محلياً بعد.
- لم تُدمج خطوط TTF الرسمية.
- لم تُنفذ اختبارات مطابقة النص الكامل.
- لم تُنفذ آلية تحديث وتنزيل شبكية.
