# ALMISHKAT V23 — تصدير مشروع متعدد المشاهد

## ما أضيف
- إضافة SceneRenderPlan إلى طلب التصدير لتمرير قائمة المشاهد وموارد كل مشهد.
- شاشة التصدير تقرأ مشاهد المشروع بترتيبها، ثم تجلب خلفية وطبقات كل مشهد.
- محرك التصدير يوزع مدة التلاوة المحددة على المشاهد بنسبة مددها المحفوظة، بحيث ينتهي الفيديو مع نهاية نطاق الصوت.
- تحميل صورة أو فيديو خلفية مستقل لكل مشهد؛ فيديو الخلفية يعاد عند الحاجة، مع فك الإطارات بمعدل 5fps.
- طبقات النص الخاصة بالمشهد تستخدم توقيتها المحلي وتحوّل إلى توقيت الفيديو العام.
- تنفيذ انتقال انزلاق للأعلى، وتلاشي عبر الأسود للانتقالين FADE وDISSOLVE. ملاحظة: DISSOLVE في هذه النسخة ليس مزجاً حقيقياً بين إطارَي المشهدين؛ إنه تلاشي عبر الأسود.
- عند عدم وجود خلفية خاصة للمشهد، يستخدم المحرك خلفية المشروع القديمة إن وجدت.
- تحديث استعلام خلفية المشروع كي لا يلتقط خلفية أحد المشاهد بالخطأ.

## حدود واختبارات لازمة
- ما زال الترميز يجمع عينات الفيديو المشفرة في الذاكرة قبل بدء muxer؛ لم يتحقق البث المباشر بعد.
- الصوت يظل مسار التلاوة المختار فقط؛ صوت فيديو الخلفية لا يدمج.
- لا توجد معاينة مركبة مسبقة للمشاهد.
- لا يوجد إلغاء أو استئناف للتصدير.
- لم يُبن APK ولم يُختبر على جهاز فعلي. لا يوجد Gradle Wrapper أو تثبيت Gradle في بيئة العمل الحالية.
- يجب اختبار مشروعات بلا مشاهد، ومشهد واحد، وعدة مشاهد، وخلفيات صور وفيديو، وانتقالات مختلفة، ومدد صوت مختلفة عن مجموع مدد المشاهد.
