# ALMISHKAT V12 — حفظ نطاقات المقاطع الصوتية

## ما أضيف
- جدول SQLite باسم audio_clip_selections.
- ترقية قاعدة البيانات من الإصدار 3 إلى 4 دون حذف بيانات المصحف أو المشاريع أو التوقيتات.
- حفظ نطاق القص باسم الملف URI ووقت البداية والنهاية ومعرف مستقل وتاريخ الإنشاء والتحديث.
- استعراض النطاقات المحفوظة لكل ملف صوتي.
- استعادة نطاق محفوظ إلى منزلقات التحديد.
- حذف نطاق محفوظ.

## حدود النسخة
- النطاقات مرتبطة بمصدر الصوت URI وليست بعد مرتبطة بمعرف مشروع StudioProject.
- لا يتم قص الصوت أو إنشاء ملف جديد؛ هذه علامات تحرير غير هدّامة.
- صلاحية URI الدائمة وإدارة الملفات المنقولة/المحذوفة تحتاج معالجة لاحقة.
- لا يوجد تشغيل للنطاق المحدد أو تصدير MP4 في هذه المرحلة.
- لم يتم بناء APK أو اختباره على جهاز Android فعلي.
