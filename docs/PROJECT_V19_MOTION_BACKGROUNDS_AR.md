# ALMISHKAT V19 — خلفيات الفيديو والحركة النصية

## ما أضيف
- ترقية قاعدة البيانات إلى الإصدار 8 وإضافة video_uri لخلفية كل مشروع.
- اختيار ملف فيديو من الهاتف وحفظ صلاحية القراءة الدائمة.
- استخراج إطارات خلفية الفيديو أثناء التصدير باستخدام MediaMetadataRetriever.
- تكرار الخلفية عند تجاوز مدتها مدة مقطع التلاوة.
- أولوية فيديو الخلفية ثم الصورة ثم القالب اللوني.
- تلاشي دخول وخروج طبقات النص خلال 400ms.
- يبقى التصدير محلياً دون إنترنت.

## الحدود
- استخراج إطار لكل إطار تصدير ثقيل وقد يكون بطيئاً.
- صوت فيديو الخلفية لا يدمج؛ صوت التلاوة المختار هو المسار الصوتي.
- لا توجد انتقالات بين مشاهد متعددة أو keyframes عامة.
- يلزم اختبار توافق الترميزات والأجهزة.
- لم يُبن APK ولم يُختبر على هاتف فعلي.
