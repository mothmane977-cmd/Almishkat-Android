# محرك القرآن والتزامن — ملاحظات التنفيذ

## ما تم في V3
1. اختيار ملف صوت محلي باستخدام Storage Access Framework.
2. تشغيل الصوت محلياً عبر Android MediaPlayer.
3. إدارة موضع التشغيل والمدة.
4. تعريف `AyahTiming` بالمللي ثانية.
5. حساب الآية النشطة من موضع التشغيل.
6. فحص التوقيتات وإظهار الأخطاء البنيوية.
7. تعديل بداية ونهاية كل آية يدوياً عبر منزلقات.

## قرارات السلامة والدقة
- لا يُنشأ نص قرآني تلقائياً ولا يُعرض نص غير موثّق على أنه قرآن.
- يجب اختيار مصدر نص معتمد وتوثيق الإصدار والرواية ورقم السورة والآية.
- لا يجوز استخدام المحاذاة الصوتية التلقائية دون مراجعة بشرية؛ تقترح كأداة مساعدة فقط.
- عند استيراد نص المصحف، يلزم فحص عدد الآيات وبصمة المصدر ومقارنة النص قبل السماح بالتصدير.

## الخطوة التقنية التالية
- إضافة مخطط بيانات محلي للسور والآيات مع provenance (المصدر، الإصدار، الرواية).
- حفظ مشروع التوقيت محلياً واستعادته بعد إغلاق التطبيق.
- إضافة تقسيم موجة الصوت وتحديد نقاط البداية/النهاية بدقة.
- لاحقاً: محاذاة كلمة/آية مع صوت القارئ مع شاشة مراجعة بشرية.
