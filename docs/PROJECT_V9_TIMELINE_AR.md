# ALMISHKAT V9 — الخط الزمني متعدد المسارات

## ما أضيف
- نموذج بيانات للمقاطع والمسارات: خلفية، آيات، تلاوة، ترجمة، مؤثرات.
- شاشة خط زمني لمدة مشروع تجريبية 60 ثانية.
- مؤشر تشغيل يمكن تحريكه زمنياً.
- تحديد المسار النشط وإضافة/حذف مقطع تجريبي.
- قواعد تحقق من المدد السالبة أو الصفرية أو تجاوز مدة المشروع.
- دمج تبويب «الخط الزمني» داخل الاستوديو.

## حدود هذه النسخة
- المقاطع المعروضة تجريبية وغير محفوظة في SQLite بعد.
- المخطط ليس موجة صوتية مستخرجة من الملف.
- لا يدعم سحب المقاطع أو قصها أو تحريك حوافها بعد.
- لا يوجد دمج فعلي للصوت والفيديو أو تصدير MP4 بعد.
- يلزم ربط المقاطع بمعرف المشروع ثم اختبارها على جهاز Android.
