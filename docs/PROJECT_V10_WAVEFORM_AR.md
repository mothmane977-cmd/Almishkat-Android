# ALMISHKAT V10 — استخراج الموجة الصوتية

## ما أضيف
- اختيار ملف صوت محلي عبر منتقي ملفات Android.
- فك ترميز المسار الصوتي باستخدام MediaExtractor وMediaCodec.
- تحليل عينات PCM واختزالها إلى 240 قمة صوتية لتمثيل الموجة.
- عرض الموجة في واجهة Compose.
- تنفيذ التحليل في Dispatchers.IO حتى لا تتجمد الواجهة.
- دعم بيانات معدل العينة وعدد القنوات والمدة.

## حدود النسخة
- الموجة تمثل مستوى الصوت ولا تحدد كلمات أو آيات تلقائياً.
- لا توجد بعد أدوات سحب لتحديد نقاط القص فوق الموجة.
- لا يوجد ربط آلي بين قمم/صمت الصوت وتوقيت الآيات.
- لا يوجد تصدير MP4 أو محرك تركيب فيديو بعد.
- يجب اختبار صيغ صوت متعددة على أجهزة فعلية؛ بعض الترميزات أو ملفات VBR قد تتطلب معالجة خاصة.
- لم يتم تنفيذ build APK أو اختبار التشغيل على هاتف ضمن هذه الجلسة.
